# Credence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Credence, a prediction-market companion that scores onchain traders on skill, stores what it learns in Walrus Memory on Mainnet, and uses that memory to publish a Sharp Line, before 2026-11-10 17:00 UTC.

**Architecture:** Next.js app (UI + API routes) over a SQLite/Turso cache. A tick-based engine pulls Tatum Prediction API data, scores voices with pure tested functions, and writes distilled knowledge to Walrus Memory through a rate-limited queue. Tatum Sui RPC verifies the memory account and anchors receipts. The local DB is disposable; learned state can be restored from Walrus.

**Tech Stack:** Next.js 16.4.3 (App Router, React 19, Tailwind), TypeScript, Vitest, Drizzle ORM + @libsql/client, zod, @mysten-incubation/memwal 0.1.12, @mysten/sui ^2.38.0, tsx.

**Spec:** `docs/superpowers/specs/2026-10-31-credence-design.md`

## Global Constraints

- Repo root is `D:\downloads\tatum\credence`. Node ≥ 20 (local 22.14). Package manager npm.
- Pinned: `next@16.4.3`, `@mysten-incubation/memwal@0.1.12`, `@mysten/sui@^2.38.0`.
- Walrus Memory is **Mainnet only**: `MEMWAL_SERVER_URL` defaults to `https://relayer.memory.walrus.xyz`.
- Tatum base `https://api.tatum.io/v4/data/prediction`, header `x-api-key`. Client limit **4 req/s**. Daily credit cap `TATUM_DAILY_CREDIT_CAP` (default **60000**). Credits: list/get market 100, positions 100, wallet history 100, top traders 200, price history 200.
- Tatum Sui RPC `https://sui-mainnet.gateway.tatum.io`, same `x-api-key`.
- App memory budget: 5 points per remember, **400 points/hour, 50 points/minute** (below the relayer's 500/60).
- Every memory text goes through `encodeMemory`; namespaces only from `NS` (`credence-voices`, `credence-calls`, `credence-lessons`, `credence-checkpoints`, `credence-user-<handle>`).
- Times are stored as epoch milliseconds (UTC). Prices and probabilities are numbers in [0, 1].
- Secrets only in `.env.local` (gitignored). `.env.example` is committed. Modules touching keys import `server-only`.
- Scoring constants (spec §5): K = 10; credibility = 50 + 50·tanh(z/3); MIN_CREDIBILITY = 55; MIN_WEIGHT = 1.0; λ₀ = 0.25; κ = 0.5; λ max 0.6.
- Scripts run as `npx tsx --env-file=.env.local scripts/<name>.ts`. Tests run as `npx vitest run <path>`.
- UI tasks load the `frontend-design` skill, and charts load the `dataviz` skill, before writing components.

## Review Focus

1. **Tatum 429/5xx, timeouts, or null fields:** the tick finishes its other stages, and pages render cached data labeled with its age. Pinned by tests in Task 2 (retry, nullable schemas) and Task 10 (failing stage doesn't stop the tick).
2. **Relayer failure or 429 on memory writes:** rows stay `queued` with `attempts` incremented and are never dropped. After 5 attempts they become `failed` and are visible on Brain. Pinned in Task 3.
3. **Markets whose outcomes array isn't length 2, or has missing prices:** no Sharp Line, no crash, and the market still lists. Pinned in Task 7.
4. **A pick at or after close time, or on a resolved market:** rejected with `MARKET_CLOSED`. Pinned in Task 11.
5. **Missing optional keys (memory, Sui signer, odds):** the app renders with a banner, the engine skips those stages, and memories stay queued. Pinned in Task 1 (feature flags) and Task 10 (tick with `memory = null`).
